This project is useful for people who are tracking the race results and the overall profit of the formula 1 season. It takes the revenue and operating costs of each venue and turns into EUROS for accurate data. The program is also very easy to update with more information, as you just need to add another type of currency in the transformers.py file. You can even change what currency you want to change to by just changing the values. This project was done by only me, with help from an example project that was made by Prof. Espinosa.
